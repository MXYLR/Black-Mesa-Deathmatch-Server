// 让单人战役的 tau cannon 拥有多人模式行为所需的三个入口（Black Mesa server.dll）：
//
//  1. CMultiplayRules::IsMultiplayer  —— gamerules 虚函数（vtable 索引 34 = 字节偏移 0x88）。
//     BM 的 tau 代码在开火时读 [g_pGameRules]->vtable[0x88] 判定单人/多人分支。
//     插件仅在 tau 的两个函数执行期间覆盖它的返回值。
//
//  2. CWeapon_Tau::FireBeam (0x1048c780) —— 击退分支。单人分支把垂直分量清零
//     （mov dword ptr [ebp-0x18], 0 @ 0x1048ca18）→ 单人无高斯跳；多人分支保留三轴。
//
//  3. CWeapon_Tau::ChargeFire (0x1048d6e0) —— 蓄力副攻的开火/冷却分支。
//     单人把副攻冷却设成「当前时间 + 开火动画时长」，多人设成「立即可再射」。
//     BM 未导出该函数名，此处按行为命名。
//
// 签名与 vtable 索引来源：SourceCoop (ampreeT/SourceCoop) gamedata/srccoop.games.txt，
// 已用本地 F:\BMServer\bms\bin\server.dll (md5 68278cc0c3a1e23d96c2b9d722ae7670) 复核唯一命中。
